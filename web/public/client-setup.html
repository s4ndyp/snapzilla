Windows capture-client

De Snapzilla-client draait in het systeemvak en uploadt screenshots direct naar deze server. Download de installer uit GitHub Releases (gebouwd bij elke merge naar main).

Installatie

  1. Installeer SnapzillaSetup.exe van Releases.
  2. Open Snapzilla uit het systeemvak → Instellingen.
  3. Zet Server URL op je Snapzilla-adres, bijvoorbeeld http://192.168.1.10:3000 (zonder slash aan het eind).
  4. Kies een clientnaam (optioneel) en sla op.

Sneltoetsen (standaard)

  • Ctrl+Shift+F11 — volledig scherm
  • Ctrl+Shift+F12 — actief venster
  • Ctrl+Shift+S — regio selecteren

API-endpoint (handmatig testen)

POST /api/collections/screenshots/records
Content-Type: multipart/form-data

image=@screenshot.png
title=Test
captured_at=2026-10-25T12:00:00.000Z
capture_mode=upload
client_id=my-pc
client_name=Werk-PC

Docker op Proxmox LXC

git clone https://github.com/s4ndyp/snapzilla.git
cd snapzilla
cp .env.example .env
docker compose up -d

Web-UI op poort 3000. PocketBase admin: /_/ (eerste keer superuser aanmaken).
